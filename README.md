# Task 2 – Data Visualization and Storytelling

A beginner-friendly Data Analyst Internship project using Python to analyze sales and create charts.

## Repository contents
- `data/sales_data.csv` – sample sales dataset (synthetic practice data)
- `src/analyze_sales.py` – Python analysis and chart-generation script
- `outputs/` – generated chart images
- `report.md` – findings, KPIs, recommendations, and limitations
- `requirements.txt` – required Python packages

## How to run
1. Install Python 3.9 or newer.
2. Open a terminal in this repository folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run:
   ```bash
   python src/analyze_sales.py
   ```
5. Open the chart images in `outputs/` and read `report.md`.

## Tools used
Python, pandas, Matplotlib.

## Dataset note
The included dataset is generated synthetic data for practice. It is not the official Superstore dataset and does not describe a real business.

## Task objective
Create visualizations that communicate a clear story, highlight key takeaways, add context, and focus on business insights rather than decoration.
